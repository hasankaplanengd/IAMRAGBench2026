# Unexecuted exploratory construction

This directory contains an exploratory two-document collusive
authority-spoofing construction.

It was used only to inspect retrieval rankings. No model generation,
semantic candidate classification, provider validation, or exact
authorization-witness experiment was conducted with this construction.

The main paper assumes at most one attacker-controlled document per
targeted task. The reported authority-spoofing result therefore uses
only the single-document `compliance_exception` construction.
