# IAMRAGBench2026 Public Release

This repository is a fresh public snapshot of the frozen
IAMRAGBench2026 experimental artifact.

For the public release, repository paths and documentation
references were changed to use venue-neutral names. The
experimental inputs, raw provider outputs, evaluation results,
result ledgers, and reported numerical findings were not
modified.

Checksum manifests that include renamed paths or updated
documentation files were regenerated after these changes.
